# 02 — AWS services

| Folder             | Console evidence                     |
| ------------------ | ------------------------------------ |
| `vpc/`             | Your VPCs + Resource Map             |
| `nat-gateway/`     | NAT gateway details                  |
| `alb/`             | Internal ALB + listeners             |
| `ecs-fargate/`     | Cluster services (FE/BE 2/2 Fargate) |
| `ecr/`             | Private repositories                 |
| `rds/`             | Instance + Multi-AZ                  |
| `cloudfront/`      | Distribution + VPC origin            |
| `secrets-manager/` | Secret overview (no values)          |
| `cloudwatch/`      | Log groups                           |
| `iam/`             | ECS execution role                   |
