Project Presentation Guidelines
Yu Luo posted on Nov 17, 2026 9:41 AM
Each team should cover the following topics in their final project presentation.

1. Project Overview
   What is your web application about?

What are its main features?

Which features have you implemented?

2. Database Design
   Which database system did you use?

What are the main entities, attributes, and relationships?

What does your database schema look like? (Include an ER diagram.)

3. Dataset
   Where does your data come from?

How much data does your database contain?

4. Queries and Indexing
   What are the main queries used in your application?

Show examples of important SQL queries.

What indexes did you create, and why?

5. Application Demo
   Demonstrate the main features of your application.

Show how your application interacts with the database.

6. Challenges and Lessons Learned
   What challenges did you encounter?

What did you learn from this project?
